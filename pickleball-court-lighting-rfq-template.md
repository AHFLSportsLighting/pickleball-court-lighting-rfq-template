# Pickleball Court Lighting RFQ Template

This reusable worksheet helps a venue team collect the site inputs a lighting designer or supplier needs before comparing fixtures. It supports RFQ preparation and does not replace a project-specific photometric design or compliance review.

## Required inputs

| Area | Record |
| --- | --- |
| Court geometry | Court count, dimensions, orientation, and adjacent activity areas |
| Mounting | Pole, wall, or ceiling coordinates; mounting height; setback; maintenance access |
| Electrical | Voltage, phase, circuits, controls, and surge exposure |
| Performance | Intended use, maintained illuminance target, uniformity criteria, and glare-sensitive directions |
| Project records | Layout drawings, site photographs, fixture photometry, and handover requirements |

## Review workflow

1. Map actual mounting coordinates before discussing fixture quantity.
2. Compare the proposed photometric file with the project layout.
3. Record glare-sensitive sightlines and spill-light constraints.
4. Agree the aiming schedule, controls, and commissioning record before handover.

## Fixture reference

For a waterproof outdoor fixture reference to include in an RFQ, review the [AHFL-P9 pickleball court light](https://aihuafeili.com/product/ahfl-p9-waterproof-pickleball-court-light/). A project-specific layout still requires actual site dimensions, mounting positions, and voltage.

## Scope note

This template does not establish fixture quantity, lux levels, layout approval, or regulatory compliance. Those decisions require the project's verified site data and relevant local requirements.
