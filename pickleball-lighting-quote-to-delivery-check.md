# Carry the pickleball lighting RFQ into the receiving record

Use this companion worksheet when the fixture package is priced and again when it arrives. Give each fixture group a short ID that appears on the layout, quote and purchase order. Ask the supplier how the packing list identifies that group.

| Check | Before ordering | At delivery |
|---|---|---|
| Fixture group | Save model, optic, input power and control option | Compare the labels and approved schedule |
| Mounting kit | List brackets and accessories separately | Count packages against each packing-list line |
| Configuration changes | Attach the accepted revision to the order | Record any label or configuration that needs confirmation |
| Energy budget | Record fixture input and expected light-on hours by zone | Update the estimate if a different configuration is approved |
| Exceptions | Identify who owns the decision | Save photos, record the affected quantity and hold the item pending review |

## Example

A quote includes two fixture groups with the same housing and different optics. The shipping labels identify the housing only. Record both quantities received and leave the optics marked as unverified until the supplier provides evidence tied to the shipment. Give the installer the approved schedule and the disposition of any held items before releasing equipment.
