# Record actual light-on hours before revising a pickleball lighting budget

Run this check over a representative booking period. Keep one row per lighting zone and scene. If an adjacent court shares a switch, identify the shared group before adding hours to the estimate.

| Date | Zone and scene | Light-on time | Light-off time | Reason for extra operation | Source |
|---|---|---|---|---|---|
| | | | | Setup, cleaning, coaching or override | Controller log or staff observation |

## Reconcile the schedule

1. Compare the first and last switching times with the booking record.
2. Mark which part of the session used a dimmed scene. Use confirmed scene input power if it is available.
3. Flag shared zones and overlapping bookings so the same operating hours are counted once.
4. Keep exceptions visible. A tournament, maintenance visit or holiday schedule may need a separate estimate.

In an illustrative example, bookings run from 18:00 to 21:00, while the court lights run from 17:45 to 21:20. Use 3 hours and 35 minutes for that scene, and record why the extra 35 minutes occurred.

Transfer the reconciled hours to the [pickleball lighting electricity cost worksheet](https://aihuafeili.com/pickleball-court-lighting-electricity-cost/). If light-on time differs from the intended schedule, use the [court lighting controls guide](https://aihuafeili.com/pickleball-court-lighting-controls/) to identify which zone or operating scene to review with the facility team.
